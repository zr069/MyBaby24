# Roadmap

## Phase 1 -- Eltern-App (aktuell)
- [x] Wachstum (Gewicht, Groesse, Kopfumfang, Verlaufskurven)
- [x] U-Untersuchungen (U1-U9, Zeitfenster, Inhalte, Status)
- [x] Impfungen (STIKO-Kalender, Statusverfolgung, Elterninfo)
- [x] Bilirubin-Archiv (migriert aus BiliTracker)
- [x] Kind-Profil mit Stammdaten
- [x] Dashboard mit altersabhaengigen Themen
- [ ] Perzentilenvergleich (WHO/KiGGS-Daten)
- [ ] Ergebnis-Eingabe fuer U-Untersuchungen
- [ ] Profil-Bearbeitung

## Phase 2 -- Erweiterungen
- [ ] PDF-Export fuer Kinderarztbesuch
- [ ] Termin-Reminder (lokale Benachrichtigungen)
- [ ] Mehrere Kinder unterstuetzen
- [ ] Dokumenten-Upload (Befunde, Arztbriefe)
- [ ] Erweiterte Wachstumsanalyse mit Trendwarnung

## Phase 3 -- Arztzugang
- [ ] Strukturierte Arzt-Eingabe
- [ ] Sichere Freigabe durch Eltern
- [ ] Datenschutzkonzept (DSGVO-konform)
