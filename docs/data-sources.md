# Datenquellen

## Primaerquellen

### G-BA Kinder-Richtlinie
- Inhalt und Zeitfenster der U-Untersuchungen (U1-U9)
- Offizielle Grundlage fuer das Kinderuntersuchungsheft (Gelbes Heft)
- URL: https://www.g-ba.de/richtlinien/15/

### RKI / STIKO Impfkalender
- Impfempfehlungen fuer Saeuglinge, Kinder und Jugendliche
- Wird regelmaessig aktualisiert
- URL: https://www.rki.de/DE/Content/Kommissionen/STIKO/Empfehlungen/Aktuelles/Impfkalender.html
- Letzte Pruefung: 2026-01

### Kinderuntersuchungsheft (U-Heft_Digi.pdf)
- Persoenliche digitale Kopie des gelben Heftes
- 113 MB Scan-PDF, daher nicht vollstaendig automatisch extrahierbar
- Ergaenzt durch offizielle G-BA-Inhalte

### kindergesundheit-info.de (BZgA)
- Elterninformationen zu Vorsorgen und Kindergesundheit
- URL: https://www.kindergesundheit-info.de

## Nicht verwendet
- Foren, Blogs, ungesicherte KI-Zusammenfassungen
- Werbliche Quellen
- Internationale Leitlinien (nur deutsche Quellen)

## Quellenstruktur im Code
Jeder medizinische Datenblock enthaelt:
- `source`: Quellenangabe
- `lastReviewedAt`: Datum der letzten Pruefung
- Kommentare im Code bei Unsicherheiten
